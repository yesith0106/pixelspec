Frequently asked
questions

Everything you need to know about inspecting, measuring and annotating your UI with PixelSpec.

What is PixelSpec?

PixelSpec is a free, open-source visual feedback tool and CSS inspector for websites. It runs as an overlay on your live site in development, so you can measure spacing, typography and color, pin notes to elements, and copy precise feedback for your AI coding agent.

How do I measure spacing and padding on a website?

Turn on PixelSpec and hover any element. Padding shows in green, margin in orange and the gaps between children in pink, with the value in pixels. Hover a second element to see the exact distance between the two.

Does it work with my AI coding agent?

Yes. Press C to copy every note as compact text or full Markdown, then paste it into Claude Code, Cursor, Codex, Copilot or any agent that reads text. Each note includes the selector, component, size and styles, so the agent finds the right element.

Is PixelSpec for designers or developers?

Both. Designers use it for design QA on the real build: check spacing, type and color against the design, then leave notes on the exact element instead of sending screenshots. Developers and vibe coders use it to turn “this looks off” into precise instructions their AI coding agent can fix in one pass.

How does PixelSpec help with vibe coding?

When you build with an AI agent, describing visual bugs in words is the slow part. With PixelSpec you click the element, type what should change and copy. The agent gets the selector, component name, size, spacing, font and colors with every note, so it edits the right element without guessing.

Will PixelSpec affect my production site?

No. You load it only in development, it renders inside its own shadow root so it never changes your styles, and it has zero runtime dependencies.

Which frameworks does it support?

Any website. Install it from npm for React, Next.js, Vite, Vue or Svelte, or add one script tag to plain HTML. React, Vue and Svelte component names are detected automatically.

How does the color contrast check work?

PixelSpec reads the text color and the real composited background behind it, then shows the WCAG contrast ratio and whether it passes AA or AAA.

Is PixelSpec free?

Yes. PixelSpec is open source under the MIT license, free for personal and commercial use.
