For designers working with AI

Point at the pixel. Tell your AI exactly what to fix.

PixelSpec puts Figma-style inspect on top of your live site. See the spacing, type, color and contrast, click an element to leave feedback, and hand your coding agent instructions it can act on.

$ npm i -D pixelspec

Or press Alt Shift I anywhere on this page. It's running live.

Why PixelSpec exists

Designing with AI lost the inspect panel.

More and more designers skip the handoff and build straight in code with Claude Code, Cursor or v0. The design lives in the browser now. The tools we rely on didn't come with it.

In Figma you can see that a gap is 14px when it should be 16, that the line height is off, or that a label fails contrast. On a live page you can't, so feedback turns vague: "make it a bit more spacious", "the title feels heavy". The agent guesses, you go back and forth, and the details drift.

PixelSpec brings that precision back. You see the same numbers you would in your design tool, on the real thing, and every note you leave carries them, along with the exact element, so the agent knows what to change and where.

How it works

Inspect, annotate, paste. That's the whole loop.

No plugin, no screenshots, no account. It runs on your local dev server or any page you can add a script tag to.

Annotate

Type what you want changed and press Enter. A numbered marker sticks to the element. Select text to quote it. Notes survive reloads.

Copy for AI

Press C and paste into your agent. Each note comes with its selector, component name and only the specs that matter, in a compact format that saves tokens.

What you can see

The inspect panel you're used to, on the live page.

Spacing overlay

Padding in green, margin in orange, flex and grid gaps hatched in pink.

Redlines

Distances between any two elements, like Figma. Hold Alt to measure to the parent.

Typography

The rendered font, size, weight, line height and letter spacing in px, em and percent.

Color and contrast

Text and background colors with the WCAG ratio against the actual background.

Component names

React, Vue and Svelte components are detected so the agent finds the right file.

Stays out of the way

Zero dependencies. It lives in a shadow root, so it never touches your styles.

PixelSpec vs Agentation

Agentation tells your agent where. PixelSpec also tells it what's there.

Agentation made click-to-annotate feedback for AI agents popular. PixelSpec keeps that idea and adds the design layer, so your notes come with the measurements a designer would check.

Install

Running in under a minute.

Add it to your dev build only, then click the round button in the corner or press Alt Shift I.

// npm i -D pixelspec
import { PixelSpec } from 'pixelspec/react';

export default function App() {
  return (
    <>
      <YourApp />
      {process.env.NODE_ENV === 'development' && <PixelSpec />}
    </>
  );
}
// npm i -D pixelspec, then in main.ts
if (import.meta.env.DEV) {
  import('pixelspec').then(({ init }) => init());
}
<!-- Before </body> -->
<script src="https://unpkg.com/pixelspec"></script>
