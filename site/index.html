PixelSpec is the inspect panel for designers who build with AI.

See the spacing, type, color and contrast on your live site, the way you would in Figma. Click an element to leave a note, then hand your AI agent feedback it can act on. A sharper take on Agentation.

$ npm i -D pixelspec

Or press Alt Shift I anywhere on this page.

Why

Designing with AI lost the inspect panel.

Designers now build straight in code with Claude Code, Cursor or v0. Without specs on screen, feedback turns vague ("make it a bit more spacious") and the agent guesses. PixelSpec shows the numbers you'd see in Figma and attaches them, with the exact element, to every note.

Install

Add it to your dev build.

// npm i -D pixelspec
import { PixelSpec } from 'pixelspec/react';

export default function App() {
  return (
    <>
      <YourApp />
      {process.env.NODE_ENV === 'development' && <PixelSpec />}
    </>
  );
}
// npm i -D pixelspec, then in main.ts
if (import.meta.env.DEV) {
  import('pixelspec').then(({ init }) => init());
}
<!-- Before </body> -->
<script src="https://unpkg.com/pixelspec"></script>
